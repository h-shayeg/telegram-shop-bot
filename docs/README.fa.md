# بازارچه، ربات فروشگاه تلگرامی

بازارچه یک فروشگاه اینترنتی کامل داخل تلگرام است. مشتری‌ها محصولات را می‌بینند، به سبد خرید اضافه می‌کنند و سفارش ثبت می‌کنند. صاحب فروشگاه هم محصولات، سفارش‌ها و گزارش فروش را از پنل مدیریتی داخل خود ربات اداره می‌کند. ربات به دو زبان فارسی و انگلیسی کار می‌کند.

این راهنما سه بخش دارد: [راهنمای مشتری](#راهنمای-مشتری)، [راهنمای صاحب فروشگاه](#راهنمای-صاحب-فروشگاه) و [نصب روی سرور](#نصب-روی-سرور).

## راهنمای مشتری

1. ربات را در تلگرام باز کنید و دکمهٔ «Start» را بزنید (یا ‎/start را بفرستید). منوی اصلی پایین صفحه ظاهر می‌شود.
2. با دکمهٔ «🛍 محصولات» یک دسته‌بندی و بعد یک محصول را انتخاب کنید تا عکس، توضیح، قیمت و موجودی آن را ببینید. برای خرید، «➕ افزودن به سبد خرید» را بزنید.
3. در «🛒 سبد خرید» تعداد هر محصول را با دکمه‌های + و − تغییر دهید، یا با «🗑 خالی کردن سبد» همه را پاک کنید. بیشتر از موجودی فروشگاه نمی‌شود به سبد اضافه کرد.
4. با «✅ ثبت سفارش» سه چیز از شما پرسیده می‌شود: نام و نام خانوادگی، شمارهٔ تلفن (تایپ کنید یا دکمهٔ «📱 ارسال شمارهٔ من» را بزنید) و نشانی تحویل. خلاصهٔ سفارش را بررسی کنید و «✅ تأیید و ثبت سفارش» را بزنید.
5. در «📦 سفارش‌های من» همهٔ سفارش‌ها و وضعیتشان را می‌بینید. تا وقتی سفارش در وضعیت «ثبت شده» است، می‌توانید آن را باز کنید و «❌ لغو این سفارش» را بزنید. هر بار که فروشگاه وضعیت سفارش را تغییر دهد، ربات به شما پیام می‌دهد.
6. با «🌐 زبان» بین فارسی و انگلیسی جابه‌جا شوید.

## راهنمای صاحب فروشگاه

مدیرهای فروشگاه کاربرانی هستند که شناسهٔ تلگرامشان در تنظیم `ADMIN_IDS` نوشته شده است. برای باز کردن پنل مدیریت، ‎/admin را بفرستید. هر وقت خواستید فرمی را نیمه‌کاره رها کنید، ‎/cancel را بفرستید.

### محصولات

1. با «🗂 افزودن دسته‌بندی» نام یک دسته‌بندی را بفرستید، مثلاً «لوازم آشپزخانه». هر محصول باید در یک دسته‌بندی باشد.
2. با «➕ افزودن محصول» دسته‌بندی را انتخاب کنید و به‌ترتیب این‌ها را بفرستید: نام، توضیح کوتاه (یا ‎/skip)، قیمت به تومان، تعداد موجودی و عکس محصول (یا ‎/skip). در آخر خلاصه را بررسی کنید و «✅ ذخیره» را بزنید.
3. با «📋 مدیریت محصولات» یک دسته‌بندی و بعد یک محصول را انتخاب کنید تا نام، توضیح، قیمت، موجودی یا عکس آن را تغییر دهید. با «🚫 پنهان کردن» محصول بدون پاک شدن از دید مشتری‌ها پنهان می‌شود و با «👁 نمایش دادن» دوباره دیده می‌شود.

### سفارش‌ها

- هر سفارش جدید همان لحظه با یک دکمه برای باز کردنش به شما پیام داده می‌شود.
- در «📦 سفارش‌ها» سفارش‌های باز، از جدیدترین، دیده می‌شوند. هر سفارش را باز کنید و مرحله‌به‌مرحله جلو ببرید: «ثبت شده» ← «تأیید شده» ← «ارسال شده» ← «تحویل داده شده»، یا آن را لغو کنید. مشتری در هر مرحله پیام می‌گیرد.
- با لغو شدن سفارش، چه از طرف شما چه از طرف مشتری، محصولاتش به موجودی برمی‌گردند. وقتی مشتری سفارشی را لغو کند، به شما هم پیام داده می‌شود.

### گزارش فروش

با «📊 گزارش فروش» و بعد «۷ روز اخیر» یا «۳۰ روز اخیر»، تعداد سفارش‌ها، مبلغ فروش، میانگین هر سفارش، تعداد سفارش‌های لغوشده، پنج محصول پرفروش و نمودار فروش روزانه را می‌بینید. سفارش‌های لغوشده جزو فروش حساب نمی‌شوند.

## نصب روی سرور

با این روش، ربات و پایگاه داده‌اش روی یک سرور لینوکسی با Docker اجرا می‌شوند و فروشگاه شبانه‌روز روشن می‌ماند. برای این کار برنامه‌نویسی لازم نیست؛ هر مرحله یک دستور است که باید کپی کنید.

### چیزهایی که لازم دارید

- **یک سرور مجازی (VPS)** با سیستم‌عامل Ubuntu 24.04. یک هستهٔ پردازنده، ۱ تا ۲ گیگابایت رم و ۲۰ گیگابایت فضا کافی است. سرور باید در کشوری باشد که تلگرام در آن باز است؛ سرورهای داخل ایران به تلگرام دسترسی ندارند. دامنه لازم نیست.
- **توکن ربات:** در تلگرام به [@BotFather](https://t.me/BotFather) بروید، ‎/newbot را بفرستید، یک نام و یک نام کاربری انتخاب کنید و توکنی را که می‌دهد کپی کنید.
- **شناسهٔ تلگرام خودتان،** تا ربات بداند صاحب فروشگاه شما هستید. ربات‌هایی مثل [@userinfobot](https://t.me/userinfobot) با فرستادن یک پیام، شناسه‌تان را نشان می‌دهند.

### مرحلهٔ ۱: وصل شدن به سرور

شرکتی که سرور را از آن می‌خرید، یک آدرس IP و یک رمز به شما می‌دهد. در ترمینال کامپیوترتان این دستور را بزنید و به‌جای YOUR_SERVER_IP آدرس سرور را بنویسید:

```bash
ssh root@YOUR_SERVER_IP
```

### مرحلهٔ ۲: نصب Docker

```bash
curl -fsSL https://get.docker.com | sh
```

### مرحلهٔ ۳: دریافت ربات

```bash
git clone https://github.com/h-shayeg/telegram-shop-bot.git
cd telegram-shop-bot
```

### مرحلهٔ ۴: تنظیمات

اول یک رمز برای پایگاه داده بسازید:

```bash
openssl rand -hex 16
```

بعد فایل تنظیمات را بسازید و باز کنید:

```bash
cp .env.example .env
nano .env
```

این خط‌ها را پر کنید:

| تنظیم | چه بنویسید |
| --- | --- |
| `BOT_TOKEN` | توکنی که از BotFather گرفتید |
| `POSTGRES_PASSWORD` | رمزی که همین الان ساختید (فقط حرف و عدد) |
| `ADMIN_IDS` | شناسهٔ تلگرام خودتان؛ برای چند مدیر، شناسه‌ها را با ویرگول انگلیسی (,) جدا کنید |
| `PROXY_URL` | خالی بگذارید |
| `TIMEZONE` | منطقهٔ زمانی، مثلاً `Asia/Tehran` |

به بقیهٔ خط‌ها دست نزنید؛ ربات داخل Docker خودش پایگاه داده را پیدا می‌کند. برای ذخیره، Ctrl+O و بعد Enter را بزنید و با Ctrl+X از ویرایشگر بیرون بیایید.

### مرحلهٔ ۵: روشن کردن ربات

```bash
docker compose --profile bot up -d --build
```

بار اول چند دقیقه طول می‌کشد. ربات جدول‌های پایگاه داده را خودش می‌سازد. برای دیدن وضعیت ربات:

```bash
docker compose logs -f bot
```

وقتی عبارت `Start polling` را دیدید، ربات روشن است. با Ctrl+C از دیدن گزارش‌ها بیرون بیایید؛ ربات روشن می‌ماند. حالا در تلگرام به ربات ‎/start و برای پنل مدیریت ‎/admin را بفرستید.

برای اضافه کردن محصولات نمونه (اختیاری):

```bash
docker compose --profile bot run --rm bot python -m scripts.seed_sample_data
```

اگر سرور خاموش و روشن شود، ربات و پایگاه داده خودشان دوباره روشن می‌شوند.

### دستورهای روزمره

همهٔ این دستورها را داخل پوشهٔ `telegram-shop-bot` بزنید.

| کار | دستور |
| --- | --- |
| دیدن گزارش‌های ربات | `docker compose logs -f bot` |
| راه‌اندازی دوبارهٔ ربات | `docker compose --profile bot restart bot` |
| خاموش کردن | `docker compose --profile bot stop` |
| روشن کردن دوباره | `docker compose --profile bot up -d` |
| اعمال تغییرات فایل `.env` | `docker compose --profile bot up -d` |
| به‌روزرسانی به آخرین نسخه | `git pull && docker compose --profile bot up -d --build` |

### پشتیبان‌گیری

همهٔ محصولات، سفارش‌ها و مشتری‌ها در پایگاه داده هستند. برای ساختن فایل پشتیبان:

```bash
docker compose exec -T db pg_dump -U shopbot shopbot > backup-$(date +%F).sql
```

هر چند وقت یک بار فایل‌های پشتیبان را به جای دیگری منتقل کنید، مثلاً با دستور `scp` به کامپیوتر خودتان.

برای برگرداندن پشتیبان روی یک سرور تازه، مرحله‌های ۱ تا ۴ را انجام دهید، فقط پایگاه داده را با `docker compose up -d --wait` روشن کنید و این دستور را بزنید (نام فایل را با نام فایل پشتیبان خودتان عوض کنید):

```bash
docker compose exec -T db psql -U shopbot shopbot < backup-2026-11-04.sql
```

و بعد مرحلهٔ ۵ را انجام دهید.

### رفع مشکل

- **ربات جواب نمی‌دهد:** گزارش‌ها را با `docker compose logs -f bot` ببینید.
- **عبارت `Unauthorized` در گزارش‌ها:** توکن ربات اشتباه است. مقدار `BOT_TOKEN` را در `.env` درست کنید و `docker compose --profile bot up -d` را بزنید.
- **عبارت `Conflict: terminated by other getUpdates request` در گزارش‌ها:** همین ربات جای دیگری هم روشن است، مثلاً روی کامپیوتر خودتان. آن یکی را خاموش کنید؛ با هر توکن فقط یک ربات می‌تواند روشن باشد.
- **خطای Timeout در گزارش‌ها:** سرور به تلگرام دسترسی ندارد. سروری در کشوری بگیرید که تلگرام در آن فیلتر نیست.
- **دستور ‎/admin کار نمی‌کند:** بررسی کنید شناسهٔ شما در `ADMIN_IDS` باشد و بعد `docker compose --profile bot up -d` را بزنید.
